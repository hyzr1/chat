# Hyzr product identity

Hyzr is the parent brand. Product names use the pattern **Hyzr + plain-language category**: Hyzr Chat, Hyzr Code, Hyzr Trade, and Hyzr Shop.

## Shared rules

- Use **Hyzr Chat** in titles, navigation, metadata, documentation, and customer-facing copy.
- Use **Chat** only where the Hyzr context is already obvious.
- The shared mark is a boxed italic **H**. Do not replace it with a product-specific symbol.
- Pair the mark with a two-part wordmark: `Hyzr` carries the family emphasis; `Chat` is quieter.
- Each product may keep one accent color. Chat uses cyan/teal for active controls and status.
- Repository names and subdomains use the category only: `chat` and `chat.hyzr.ai`.
- Avoid model-provider branding in the product identity. Providers are capabilities, not the Hyzr brand.

## Voice

Use direct, specific language. Describe the outcome before the mechanism. Avoid inflated AI claims, unexplained superlatives, fake metrics, and generic phrases such as “revolutionary” or “powered by cutting-edge AI.”

## Migration language

VMX is a former internal name, not a second public brand. It may appear only in compatibility code, migration notes, or historical data schemas.
